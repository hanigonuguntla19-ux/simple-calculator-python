# simple-calculator-python
A  simple calculator built using Python
# About the Project
This is a Begginer-friendly calculator project develped using python.
it allows the user to perform basic mathematical operations through a simple menu-driven program

## Features
Addition
Subtraction
Multiplication
Division
Multiple calculations
Division by zero handling
Exit option

## Technologies Used
Python

## How to run

1. Install python.
2. Download or clone this repository.
3. Open the terminal in the project folder
4. Run the following command:
python calculator.py
5. Follow the instructions displayed on the screen.
## Operations

1.Addition
2.Subtraction
3.Multiplication
